# Working specs and plans

The files in `specs` and `plans` are the designs and the step-by-step plans written while Voxa
was being built, with the help of an AI coding assistant, one or two for each milestone. The
acceptance records beside this folder, `docs/acceptance-*.md`, say how each release was
checked at the time.

They are kept as a record of how Voxa came to be as it is. Each describes the decisions made
on the day it was written, and many were changed later, while building or in a later
milestone, so they may not match the code now. Where they differ, the code, the
[README](../../README.md), [architecture.md](../architecture.md) and the decision records in
[adr](../adr) say what is true now.

Where they speak of real scans, a real export was checked on the developer's own machine and
nothing from it was recorded: no test, document, picture or commit holds anything from a real
scan.
